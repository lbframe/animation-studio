# Motion brief

Use only fields relevant to the project. Replace the prompts below with decisions; do not deliver this blank template as the animation.

## Intent

Subject, action, audience, and desired feeling. Exact text and non-negotiable details.

## Evidence

Reference location and inspected portion. Observed composition/motion/audio. Estimates and proposed additions. Unavailable evidence.

## Output

Destination and format. Aspect ratio, dimensions, duration, frame rate if exported, background/alpha. Editable source requirements.

## Motion

Loop / finite / interactive. Principal poses and beat times. Motion hierarchy, anchors, trajectories, easing, camera, occlusion, ending. Audio clock or cues if relevant.

## Route

Renderer/generator and timeline. Tool availability and version. Why this route serves this project. Assets and dependencies.

## Acceptance

Three to six observable criteria. Include reference fidelity, readability, movement, behavior, and output constraints as applicable.

## Review record

Preview inspected; timestamp or phase; specific defect; change; re-render result. Record test method and limitations. Final files and actual verification.
