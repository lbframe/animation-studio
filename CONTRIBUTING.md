# Contributing

Thank you for helping improve Animation Studio.

## Make the improvement concrete

Describe the animation task, reference, expected behavior, and actual result. Include a small reproduction or a short rendered example when it helps explain the issue. Keep private material and credentials out of submissions.

For workflow changes, explain which recurring failure the change addresses. For helper changes, check the affected behavior with representative input and document any new dependency. Keep the installable skill in `skills/create-animation/` self-contained.

## Keep the evidence accurate

Distinguish what was observed from what was estimated or proposed. A contact sheet does not verify continuous playback, a render's frame rate does not establish runtime performance, and a successful numeric seam check does not establish visual continuity.

## Add an example

Include a concise English request, input provenance, the production route, a small preview, and a description of the delivered result. Label prompts edited after the original render as suggested prompts unless they have been rerun. Include assets only when their redistribution terms are documented.

## Style

Use English for public documentation, comments, captions, and prompts. Prefer specific instructions and focused examples. Keep generated caches, dependencies, temporary frames, and large working exports out of the repository.
