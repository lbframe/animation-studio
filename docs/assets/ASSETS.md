## Rights records for the publication draft

The supplied archive does not include author/source-license records for the A-logo, B-logo, mouth-pose, garden, or hero reference images. Those entries require documentation before the corresponding media can be released with a stated reuse license.

The lyric film's source credits name SEXYMOUTH PRODUCTION, Leonardo Balland, Animation Studio, GPT 6.1 Sol, and Suno v6 Pro in their respective roles. These are credits carried by the supplied project, not a blanket license for redistribution or reuse.

The original HyperFrames projects include font notices and a bundled GSAP build. Those components retain their own terms. The Open Sans notice in the archive refers to an additional Apache license file that should accompany any redistribution of that source project.

The local review can show the supplied material. Public release packaging must resolve the relevant provenance records and preserve required notices.
